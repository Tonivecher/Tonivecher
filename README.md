# Tonivecher

I build practical web products, automation tools and Telegram-based workflows with a focus on clear UX, reliable backend logic and maintainable deployment.

## Focus areas

- Full-stack web applications with React, TypeScript, Python and Node.js.
- Telegram bots and Mini Apps for operational workflows.
- Internal business tools, booking systems, estimate calculators and lead capture flows.
- Clean product interfaces that are simple to run, maintain and extend.

## Selected work

- [umnyy-remont-site](https://github.com/Tonivecher/umnyy-remont-site) — website and Telegram Mini App for a renovation business.
- [engineering-form](https://github.com/Tonivecher/engineering-form) — premium furniture production landing page built with React, TypeScript and Tailwind CSS.

## Engineering principles

- Keep business logic separate from UI and transport layers.
- Prefer small, understandable modules over clever abstractions.
- Validate inputs, handle errors explicitly and keep deployment steps documented.
- Treat README files as part of the product: setup, scripts and operational notes should be easy to find.
